
# YR NOVATECH - Data Collection and Preprocessing

## Project Overview
This project demonstrates data collection and preprocessing using Python.

## Dataset
Adult Census Income Dataset

Source: UCI Machine Learning Repository
https://archive.ics.uci.edu/dataset/2/adult

## Technologies Used
- Python
- Pandas
- NumPy
- Google Colab

## Preprocessing Steps
1. Dataset collection
2. Missing value handling
3. Duplicate removal
4. Data cleaning
5. Outlier handling using IQR
6. Feature engineering
7. Exporting cleaned dataset

## Project Deliverables
- Raw dataset
- Cleaned dataset
- Preprocessing report
- Python source code
- Jupyter Notebook

## Conclusion
The project demonstrates a data preprocessing pipeline for preparing real-world data for further analysis and machine learning.
